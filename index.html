Design Systems

Uma biblioteca padrão, o DS Kalion, e sistemas derivados dela a partir da análise de outros projetos. Cada design system tem tokens, componentes, documentação e simulador próprios.

Sistemas

    Como nasce um novo sistema

    1. AnalisarCores, tipografia, raios, espaçamento e componentes do projeto viram um analysis.md.
    2. Derivarnpm run ds:new copia a base para systems/<nome>.
    3. AdaptarTokens, componentes novos, textos e o simulador do novo sistema.
    4. Validarnpm run ds:check e build limpos, temas claro e escuro.
